# 학급관리 고정 서명 키 전환 안내 (기존 APK → 장기 업데이트 체계)

**중요: 기존 학급관리 앱을 아직 삭제하지 마세요.** 기존 설치본의 서명 키가 보관되지 않아 새 키로는 덮어쓰기 업데이트를 할 수 없습니다. 학생 명렬·자리배치·출결 기록의 백업 및 새 앱에서 복원 완료 후 기존 앱을 정리하세요.

## A. 기존 앱에서 백업하기 (휴대폰)

1. 기존 `학급관리` 앱을 실행하여 **자리교체 → 관리(초기화·백업) → 백업 파일 저장**을 누르고 `학급자리교체_백업_날짜.json`을 안전한 위치에 저장합니다.
2. **출결 관리 → 데이터 백업 · 가져오기 · 개인정보 안내 → 전체 백업 JSON 저장**을 눌러 `학급출결_전체백업_날짜.json`을 저장합니다.
3. 2개의 JSON 파일이 실제로 존재하고 크기가 0이 아닌지 확인하세요. 중요한 경우 학교에서 승인한 개인 보관 장소에 별도 사본도 보관합니다.
4. 이 단계에서 기존 앱은 삭제하지 않습니다.

> 출결 백업을 확인하기 전 기존 앱을 삭제하면 복구할 수 없을 수 있습니다. 백업 파일에는 학생 개인정보가 포함됩니다. 공개 저장소·메신저·공개 링크에 공유하지 마세요.

## B. Windows PC에서 키 한 번 생성·등록

1. GitHub 저장소 [JB-School](https://github.com/jbmath-dot/JB-School)에서 **Code → Download ZIP**을 눌러 프로젝트를 내려받아 압축을 풉니다.
2. `class-manager-apk/scripts` 폴더의 **`1_새서명키_설정실행.bat`**을 더블클릭합니다.
3. 실행 화면에서 JDK 또는 GitHub CLI가 없다고 표시되면, PowerShell에서 아래 중 해당되는 명령으로 설치하고 **새 터미널에서** 배치 파일을 다시 실행합니다.
   - JDK 17: `winget install --id Microsoft.OpenJDK.17 -e`
   - GitHub CLI: `winget install --id GitHub.cli -e`
4. GitHub CLI 인증이 필요하면 자동으로 브라우저 인증이 열립니다. 로그인한 계정이 `jbmath-dot` 저장소에 권한이 있는지 확인하세요.
5. `MIGRATE`라고 입력해 **새 키 생성**을 승인합니다.
6. **12자 이상 강한 비밀번호**를 만들고 다시 한 번 입력해 확인합니다. **비밀번호를 반드시 별도 안전한 위치에 기록**하세요.
7. 키가 생성된 후 GitHub 암호화 Secrets 등록에 `YES`라고 입력합니다. 비밀번호나 .jks 파일을 채팅에 올리지 마세요.
8. 사용자 PC의 **`%LOCALAPPDATA%\JBMath\ClassManagerSigning\class-manager-release.jks`**에 원본 키가 저장됩니다. 이 파일과 비밀번호는 복구할 수 없으므로 접근 통제된 별도의 **암호화 백업**을 하나 더 보관하세요.
9. GitHub 저장소 → **Settings → Secrets and variables → Actions**에 `CM_SIGNING_...` 항목 6개가 생성됐는지 확인합니다. 비밀 값은 GitHub UI에서 읽을 수 없는 것이 정상입니다.

## C. GitHub Actions에서 새 키로 첫 정식 APK 빌드

1. [GitHub Actions](https://github.com/jbmath-dot/JB-School/actions/workflows/class-manager-apk.yml)에 접속합니다.
2. **학급관리 APK 검사 및 고정 키 업데이트 빌드**를 선택하고 **Run workflow**를 누릅니다.
3. 브랜치 `main`을 선택하고 **`build_signed_update`을 체크(true)** 합니다.
4. 모든 검사가 성공하면 **`ClassManager-SIGNED-UPDATE` 아티팩트**를 내려받아 ZIP에서 `app-release.apk`를 추출합니다.
5. 이 APK는 새 키로 서명된 첫 정식 설치본입니다. **이전 기존 앱 위에 설치하면 안 되며 서명 불일치로 차단되는 것이 정상**입니다.

## D. 백업 복원 후 기존 앱 정리

1. 기존 앱의 명렬·자리배치와 출결 백업 JSON을 다시 확인합니다.
2. 설치하려면 기존 `학급관리` 앱을 제거해야 합니다. **기존 앱 제거 시 앱 내부 기록은 삭제됩니다.** 반드시 백업 이후 진행하세요.
3. 새 고정 서명 `app-release.apk`를 설치합니다.
4. 새 앱에서 **자리교체 → 관리(초기화·백업) → 백업 파일 불러오기**로 자리 배치를 복원합니다.
5. **출결 관리 → 데이터 백업 · 가져오기 · 개인정보 안내 → 출결 백업 복원**으로 출결을 복원합니다.
6. 확인: 확정 자리배치, 학생 번호·이름, 과거 날짜 출결, 출석인정/질병 세부 사유, 10가지 테마가 정상인지 확인합니다.
7. 복원이 끝난 후 백업 파일과 서명 키를 별도로 보관합니다.

## E. 다음 버전부터의 업데이트

이후에는 **동일 `.jks` 키가 GitHub Secrets에 유지되고 앱의 패키지명이 `kr.jbmath.classmanager`로 동일**한 한, GitHub Actions에서 `build_signed_update=true`로 빌드한 APK를 기존 앱에 **덮어쓰기 설치**하여 출결 데이터는 보존할 수 있습니다. 자동 증가하는 `versionCode`로 이전 APK보다 높은 버전 번호를 사용합니다.

서명 키나 키 비밀번호를 잃어버리면 이후 업데이트 역시 불가능해지므로 안전한 백업이 필수입니다.
