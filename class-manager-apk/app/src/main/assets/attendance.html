기존 학급 자리교체 앱에서 배치 확정 → 백업 파일 저장을 실행한 뒤 JSON 파일을 가져오세요. 학생 이름·짝 배치도 함께 읽습니다.

새 자리배치를 가져와도 과거 출결은 삭제되지 않습니다. 날짜에 맞는 자리배치를 자동 표시합니다.

출석인정 항목은 다른 유형의 건수에서 제외하여 별도 집계합니다. NEIS 반영 전 학교 규정에 따라 확인하세요.

표시된 행을 누르면 해당 날짜로 이동합니다. 마감된 날짜는 마감을 해제해야 수정할 수 있습니다.

출결 일괄 삭제 · 날짜별 정리

자리배치와 학생 명단은 유지하고 출결 내역만 삭제합니다. 복구하려면 삭제 전 전체 백업이 필요합니다.

삭제 버튼을 누른 뒤에는 대상 날짜와 건수를 다시 확인하고 ‘삭제’를 직접 입력해야 실행됩니다. 출결 기록은 자동으로 외부에 백업되지 않습니다.

데이터 백업 · 가져오기 · 개인정보 안내
백업 파일에는 학생 이름과 출결 정보가 들어 있습니다. 개인용·학교 승인 저장소에만 보관하고, 메신저나 공개 클라우드에 게시하지 마세요.

단독 실행 시에는 이 브라우저에만 저장됩니다. PC 서버로 열면 PC와 같은 사설 네트워크에서 동기화됩니다.

이 앱은 외부 광고·분석·클라우드 API를 사용하지 않습니다. 로컬 PC 서버로 연동할 때에는 PC 전원이 켜져 있고 두 기기가 같은 신뢰할 수 있는 네트워크에 연결되어 있어야 합니다. 로컬 HTTP 통신 자체는 암호화되지 않으므로 공용 Wi‑Fi나 공개 인터넷에 노출하지 마세요.

학급 출결 관리 연결

학생 정보는 이 PC의 출결 서버에 저장되며 외부 클라우드로 전송되지 않습니다. PC 서버 실행 창에 표시된 접속 코드를 입력해 주세요.

같은 기기에서는 접속 중에만 코드를 기억하며, 브라우저 탭을 닫으면 다시 입력할 수 있습니다.

출결 입력

빠른 입력 · 조회·1~6교시·종례

출결 유형을 선택하세요.

선택한 사유는 앱의 보조 출결 기록에 저장됩니다. 출석인정 여부는 학교 규정과 증빙 확인 후 확정하세요.

교시 미참여 표시는 나이스 입력을 돕는 참고 기록입니다. 같은 날 복합 출결과 출석인정의 최종 처리는 학교 규정에 따라 확인해야 합니다.
