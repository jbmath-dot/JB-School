# 학급관리 Android APK 프로젝트

- 자리교체의 자동 섞기, 배치 확정, 자리 이력, 학급 명렬 관리 기능 포함
- 출결: 교탁 시점 학생 자리 탭, 결석·지각·조퇴·결과와 질병·인정·미인정·기타 조합
- 기기 날짜 자동 적용, 과거 날짜 정정, 월별 집계, CSV·JSON 백업
- 사진 명렬: 촬영/선택 → 앱에 포함된 한국어 OCR 모델 → 번호·이름 수동 확인/수정 → 저장
- 학생 정보와 사진은 앱에서 외부 인터넷으로 전송하지 않음. 앱에 INTERNET 권한 없음
- 학급관리의 자리교체에서 확정한 배치와 명렬을 출결 화면으로 자동 전달 (출결은 기존 기록 유지)

## 빌드
GitHub Actions 'Build 학급관리 APK' 실행 결과 아티팩트에서 app-debug.apk 설치 파일을 받으세요.
Android Studio에서 class-manager-apk 폴더를 열고 Build > Build APK(s)로 빌드할 수도 있습니다.

## 중요
기존 웹앱의 로컬 저장소와 APK 앱 저장소는 달라서 자동 이전되지 않습니다.
자리교체·출결 백업(JSON)을 각각 불러오세요. 스마트폰 화면 잠금을 설정하고 학교 개인정보 규정을 지켜 주세요.
APK 내부 데이터는 PC와 자동 동기화되지 않습니다. 업데이트 또는 삭제 전 JSON을 백업하세요.
개발용 debug APK는 서명 키가 변경되면 기존 설치본에 업데이트할 수 없습니다.


## 10가지 전체 화면 테마 (v1.1)
홈 상단의 '테마 변경' 또는 하단 '테마'에서 선택할 수 있습니다. 
- 01 네이비 골드 / 02 민트 스마트 / 03 노트 베이지 / 04 네온 블루 / 05 칠판 그린
- 06 라벤더 / 07 미니멀 블루 / 08 글래스 블루 / 09 스카이 코랄 / 10 인디고 피치
선택 즉시 홈·자리교체·날짜별 출결·명렬 사진 인식 팝업 및 입력창·버튼·좌석에 적용됩니다. 휴대폰 내 'jb-class-ui-theme-v1' 저장 키로 기억하며 기존 좌석·출결 데이터 키와 분리됩니다.
출결 의미색(출석·미입력·결석·지각·출석인정)은 테마 간에도 구별되도록 구성했습니다.

### 기존 APK 사용자가 먼저 알아야 할 사항
기존 배포본은 개발용 디버그 키로 서명되어 새 디버그 APK의 서명과 일치하지 않을 수 있습니다. 이 경우 기존 앱에 직접 덮어쓸 수 없고 삭제하면 내부 기록이 삭제됩니다.
1. **기존 앱에서 자리교체 백업 JSON과 출결 전체 백업 JSON을 각각 저장하세요.**
2. 먼저 별도 패키지 `kr.jbmath.classmanager.preview`의 **'학급관리 테마 미리보기'** APK를 설치해 테마를 확인할 수 있습니다. 기존 학급관리 앱을 삭제할 필요 없습니다.
3. 실제 교체 시 JSON 두 개를 안전하게 보관한 뒤 기존 앱 제거 → 새 학급관리 앱 설치 → 기존 JSON 복원 순서로 진행하세요.
4. 파일을 안전한 승인 저장소에 보관하고 메신저·공개 저장소에 공유하지 마세요.

## v1.2.0 · 나이스(NEIS) 스타일 교시별 출결 입력
출결 관리 → 학생 자리(또는 명렬) 터치 → 출결 유형/구분 선택 → 교시 선택 → 필요 시 세부 사유 버튼 선택 → 저장.
교시 목록은 조회, 1~6교시, 종례 총 8개 시간입니다. 학교 학사일정에 따라 실사용 교시 확인이 필요합니다.

- **결석**: 조회부터 종례까지 8개 시간이 모두 자동 선택되고 개별 해제는 할 수 없습니다.
- **지각**: 마지막 미참여 교시 하나만 터치하면 조회부터 그 교시까지 모두 선택됩니다.
- **조퇴**: 처음 미참여 교시 하나를 터치하면 그 교시부터 종례까지 모두 선택됩니다.
- **결과**: 불참한 교시를 개별 터치해 복수 선택할 수 있습니다.
- **출석/미입력**: 미참여 교시가 없습니다.
- **출석인정 결석**의 세부 사유 버튼: 감염병 / 생리 / 교외체험학습 / 기타 직접 입력.
- **질병 결석·질병 조퇴**의 세부 사유 버튼: 감기 / 복통 / 두통 / 병원진료 / 기타 직접 입력.
- 선택한 교시(\`periods\`)와 세부 사유(\`detailReason\`)는 기존 출결 JSON의 날짜별 학생 레코드에 **추가 필드**로 저장됩니다. 기존 \`status\`, \`reason\`, \`memo\`, \`time\` 필드는 유지하므로 이전 출결 기록을 그대로 확인·정정할 수 있습니다.
- CSV에는 별도 세부 사유 열 및 조회~종례 8개 열을 포함하여 미참여 시간을 \`/\` 로 표시합니다. 이는 나이스 업로드용 공식 양식이 아닌 **보조 확인 자료**입니다.
- 출석인정 항목은 홈 및 일일 현황에서 별도로 집계해 일반 결석과 혼동하지 않도록 했습니다.

### 주의
나이스와 동일한 공식 처리 시스템이 아닙니다. 같은 날 여러 종류의 지각/조퇴/결과가 발생했다면 사선 표시와 최종 마감 유형은 학교 규정에 따라 별도 판단해야 하며 이 버전은 한 학생·한 날짜에 하나의 주 유형을 저장합니다.
출석인정은 학교장의 허가·학교 규정·해당 증빙 확인이 전제됩니다. 출결 세부 사유는 민감한 정보가 될 수 있으므로 꼭 필요한 범위만 입력하고 기기의 잠금을 유지하세요.

자동 검증: \`cd class-manager-apk && node --test tests/attendance-periods.test.cjs\`

## v1.3.0 — 과거 날짜 저장, 저장 마감, 일괄 삭제, 전체 통계

### 날짜 선택 오류 보완
- 출결 날짜를 사용자가 선택하면 앱 사용 세션 안에서 그 날짜를 기억합니다. 자리교체 이동이나 배치 동기화 때문에 출결 화면이 다시 로드되어도 이전에 선택했던 날짜로 복원됩니다.
- 앱을 완전히 새로 실행한 세션은 휴대폰의 오늘 날짜가 기본입니다.
- 학생 출결 편집창을 열 때 날짜를 고정하고, 저장은 반드시 편집창의 대상 날짜로 합니다.
- 날짜 표시줄에서 작업 날짜, 마감 여부, 기록 건수를 확인할 수 있습니다.

### 저장 마감/마감 해제
- 선택 날짜를 '저장 마감'하면 closedDates 영역에 날짜·시각을 기록하고 해당 날짜의 수정 및 미입력 학생 일괄 출석을 차단합니다.
- 마감 상태에서도 날짜 조회·통계·CSV·JSON 백업이 가능합니다.
- '마감 해제' 후 해당 날짜를 다시 수정할 수 있습니다.
- 이 마감은 학급관리 앱 내부 마감이며 나이스 공식 출결 마감이나 전송이 아닙니다.

### 출결 일괄 삭제
- '현재 선택 날짜', '기간 지정', '전체 날짜' 중에서 날짜 범위를 선택할 수 있습니다.
- 마감된 날짜는 기본 제외하고, '마감된 날짜도 포함'을 직접 선택했을 때만 함께 삭제합니다.
- 삭제 대상 날짜 수와 기록 수를 표시합니다. 최종 삭제 창에서 '삭제'를 직접 입력해야 실행됩니다.
- 학생 이름과 좌석배치는 그대로 유지합니다. 삭제된 출결은 JSON 백업에서만 복구 가능하므로 삭제 전 백업을 권장합니다.

### 전체 기록 및 통계
- '전체 기록·통계' 탭: 학생별(번호 오름차순) → 해당 학생의 날짜 과거순, 날짜별(과거순) → 각 날짜의 학생 번호 오름차순 전환.
- 기록 전체 또는 선택 월 필터. 출결 유형·세부 사유·미참여 교시 표시. 행을 누르면 해당 출결 날짜로 이동합니다.
- 기존 월별 집계, 교시별 CSV, 10가지 테마와 확정 자리배치 연동은 유지합니다.

### 기기·동기화 주의
현재 Android APK에서는 위 기능이 휴대폰 내부에서 처리됩니다. 이전에 제공된 별도 PC 서버의 LAN 연동 모드에서는 안전을 위해 마감·삭제를 차단합니다. PC 서버에 새 작업 처리 규칙이 적용되었다고 주장하지 않습니다.
자동 검사: node --test tests/*.test.cjs. 실기기 갤럭시에서의 전체 조작 검증은 별도 확인이 필요합니다.
