# 학급관리 Android APK 프로젝트

- 자리교체의 자동 섞기, 배치 확정, 자리 이력, 학급 명렬 관리 기능 포함
- 출결: 교탁 시점 학생 자리 탭, 결석·지각·조퇴·결과와 질병·인정·미인정·기타 조합
- 기기 날짜 자동 적용, 과거 날짜 정정, 월별 집계, CSV·JSON 백업
- 사진 명렬: 촬영/선택 → 앱에 포함된 한국어 OCR 모델 → 번호·이름 수동 확인/수정 → 저장
- 학생 정보와 사진은 앱에서 외부 인터넷으로 전송하지 않음. 앱에 INTERNET 권한 없음
- 학급관리의 자리교체에서 확정한 배치와 명렬을 출결 화면으로 자동 전달 (출결은 기존 기록 유지)

## 빌드
GitHub Actions 'Build 학급관리 APK' 실행 결과 아티팩트에서 app-debug.apk 설치 파일을 받으세요.
Android Studio에서 class-manager-apk 폴더를 열고 Build > Build APK(s)로 빌드할 수도 있습니다.

## 중요
기존 웹앱의 로컬 저장소와 APK 앱 저장소는 달라서 자동 이전되지 않습니다.
자리교체·출결 백업(JSON)을 각각 불러오세요. 스마트폰 화면 잠금을 설정하고 학교 개인정보 규정을 지켜 주세요.
APK 내부 데이터는 PC와 자동 동기화되지 않습니다. 업데이트 또는 삭제 전 JSON을 백업하세요.
개발용 debug APK는 서명 키가 변경되면 기존 설치본에 업데이트할 수 없습니다.
