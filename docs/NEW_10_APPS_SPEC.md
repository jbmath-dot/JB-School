# JB School 신규 10개 오프라인 앱 — 기능·화면·데이터 설계서

버전: v0.4.0 / 2026-10-31. 목적은 **실제 학교 운영에 필요한 기능의 로컬 우선 MVP 구현**입니다. 최종 공식 규정 준수 또는 개인정보 처리를 승인하는 소프트웨어가 아닙니다.

## 설계 원칙

- 기존 7개 앱의 메뉴와 로컬 데이터(`jb-school-demo-v1`, `jb-school-modules-v2`)를 유지하며, 새 10개 앱은 별도 `jb-school-extras-v1` 키에 저장합니다.
- 신규 10개 앱의 모든 항목은 `id`를 가진 명시적 행으로 저장됩니다. 화면에서 작성·수정·삭제, CSV 내려받기·가져오기, 자동 점검 결과 TXT 내려받기를 제공합니다.
- 통합 백업은 버전 2 JSON (`format: jb-school-local-backup`, `responses`, `modules`, `extras`)로 생성합니다. v1 복원도 지원하며, v1 파일 복원 시에는 현재 신규 앱 데이터가 유지됩니다.
- 서버 호출, 실시간 동기화, 계정 인증, 채점 결과 공식 제출을 구현하지 않습니다. **사이트 공개 상태에서 개인정보·내부자료를 입력하지 않습니다.**
- 사용자 입력은 항목별 길이, 날짜·시간, 숫자, 중복, 만점 범위를 검증합니다. CSV 내보내기는 스프레드시트 수식 주입을 완화합니다. 파일 업로드는 750KB 및 최대 600행으로 제한합니다.
- 반응형 대시보드, PC 좌측 탐색, 모바일 메뉴, 입력폼, 결과표, 통계, 오류 안내, 가상 예제 넣기를 공통 적용합니다. 완료된 달력 일정은 기본적으로 숨기며 보관과 비슷한 동작을 제공합니다.

## 각 앱 업무 흐름과 데이터 모델

| 앱 ID | 흐름 | 핵심 필드 | 주요 자동 계산 및 출력 | 현재 미구현/확인 필요 |
|---|---|---|---|---|
| `proctor` | 교사·제약 입력 → 시간표 입력 → 자동 배정 → 중복 확인 → 수동 수정 → CSV | 날짜·교시·교실·교사ID·감독/대체 | 동일 시간 동일 교사 중복 차단, 배정불가 차단, 누적 횟수 기준 균형 | 교사별 수업시간표, 정·부감독, 학년별 복수 제약, 학교 감독 규정 반영 |
| `items` | 문항 추가 → 선다형 정답·배점 설정 → 검토 → CSV/TXT | 번호·내용 요소·유형·정답·배점·난이도 | 목표점수 비교, 정답 1~5 분포, 번호 중복 차단 | PDF/HWPX 수식·정답 자동 판독, 정답 수학적 검증 |
| `awards` | 대상자 가상ID → 공적 사실 입력 → 검토 → TXT | 대상·표창 종류·공적기간·공적 내용·검토상태 | 공적조서 문장 템플릿, 상태별 건수 | 공식 기관별 서식 자동 생성, 공적 사실·기간·중복 수상 검증 |
| `activities` | 창체·봉사 활동 각각 입력 → 동시간 중복 탐지 → CSV | 가상ID·날짜·시작/종료·영역·활동 | 동일 학생·날짜의 구간 겹침 탐지 | 중복기재 허용 여부 판단 및 공식 학생부 규정, 자정 넘김 |
| `seating` | 가상 학생 명단 → 시드·열·모둠 수 → 셔플 → 배치도 → 수동 수정 | 학생ID·모둠·좌석·메모 | 결정적 셔플, 중복 ID/좌석 차단, 모둠 인원 집계 | 학생 간 분리 조건·특수좌석·성적 기반 편성 및 교실 구조 |
| `tutoring` | 학생ID·회차/목표 입력 → 상태 변경 → 후속 지도 → CSV | 가상ID·일자·주제·목표·상태·메모 | 학생별 회차·보충필요 목록 | 학생 실명 정보, 학습진단 자동 채점, 성취도 측정 검증 |
| `calendar` | 업무·마감일 입력 → 사전 준비일 계산 → 완료 구분 → CSV | 업무명·마감일·준비일수·담당ID·진행상태 | 날짜 차감, 준비 필요·마감 초과 감지 | 외부 일정 자동 불러오기, 공식 학교 학사일정 연동, 실시간 알림 |
| `contest` | 대회별 가상 참가자·심사위원 입력 → 루브릭 점수 → 집계 → CSV | 대회명·참가ID·심사ID·논리(40)·창의(40)·표현(20) | 위원별 합계, 참가자 평균, 공동 순위, 중복 심사 방지 | 대회별 맞춤 배점, 결시·동점 세부 기준·심사위원 수 불균형 반영 |
| `fieldtrip` | 준비업무 등록 → 안전·교통·안내 카테고리 체크 → 기한 검토 | 업무명·분류·기한·담당ID·상태·메모 | 미완료·기한경과 카운트, 기한 정렬 | 필수 공식 서식, 안전점검 규정, 보험/버스 예약 연계 |
| `workload` | 가상 교사별 업무·시간·가중치 입력 → 비교 → 재배치 초안 | 가상교사ID·업무·분류·월 시간·가중치 | 가중 업무시간 합, 최대-최소 편차 | 정성적 업무 난이도, 공정 인사 판단, 인사 기록 보호 |

## UI 구성

```
JB School (17개 앱)
├── 통합 홈 (최근 회신·기존 7개 카드·신규 10개 카드)
├── 기존 7개 앱 (기존 화면과 동작 그대로)
├── 신규 10개 앱
│   ├── 업무 설명/개인정보 주의 문구
│   ├── 좌측: 항목 등록/수정 + 업무별 자동 도구 + CSV 불러오기
│   └── 우측: 저장 목록/수정·삭제 + 자동 점검 통계/결과 + CSV·TXT
└── 전체 데이터 관리: v2 JSON 내보내기/복원 (v1 호환)
```

## 데이터 구조

```json
{
  "format": "jb-school-extras",
  "version": 1,
  "modules": {
    "proctor": [], "items": [], "awards": [], "activities": [],
    "seating": [], "tutoring": [], "calendar": [], "contest": [],
    "fieldtrip": [], "workload": []
  },
  "config": {
    "proctor": {"teachers": "", "unavailable": ""},
    "items": {"target": "100"},
    "seating": {"students": "", "columns": "3", "groups": "2", "seed": "2026"}
  }
}
```

단일 항목은 `{id:UUID, ...앱별 필드(문자열)}` 형태이며 저장 전 스키마를 검증합니다. 브라우저 용량 한도·공용 PC·시크릿 모드·데이터 삭제 위험이 있으므로 비식별 가상 자료만 넣습니다.

## 기능 검증

- `node --test tests/*.test.cjs`: 기존 25 + 신규 12 = 37개 검증.
- `python tests/extra_browser.py`: 10개 앱의 입력·수정·CSV 출력, 자리/감독 자동편성, 표창 TXT, 통합 백업 복원. 테스트 환경의 로컬 HTTP 접근 차단으로 가상 DOM 실행 기반 검사에 한정합니다.
- 실제 PWA 오프라인 네트워크 차단 재접속과 Edge/Windows 앱 설치, 학교 공식 문서 양식 검증은 **미완료**입니다.

## 우선순위 후속 개발 (서버 기능 제외)

1. 실제 PC·브라우저 실기기에서 오프라인 캐시/재접속·업데이트·기기별 복원 검사.
2. 학교별 평가계획·학사규정·감독 배정 기준·심사 규정을 설정으로 분리.
3. 공식 서식으로 내보내기 지원 전에 검증 가능한 샘플 및 서식 권한 확보.
4. 점수·표창·학생부·안전·인사 관련 자동 결과는 참고자료로 표시하고 담당자가 수동 확인.
5. 서버 인증·공동 데이터베이스·실시간 동기화는 사용자 요청에 따라 **후순위** 유지.
