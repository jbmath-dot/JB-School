# 교사 요구 기반 전교사·전학급 시간표 자동편성 — 25번째 앱 설계 (v0.6 1차 구현)

상태: **로컬 JS 제약 탐색 엔진·교사 요청 일괄 업로드 UI·복수 유효안 비교·XLSX 출력 구현**. 실학교 규모와 미지원 복합제약 등은 `timetable/README.md`에 구분했습니다.

## 목표

교사별 요청 양식(.xlsx/CSV) 여러 개와 학교의 학급별·교사별 주간 수업 배정표를 업로드하여, 모든 필수 제약을 만족하는 시간표를 복수 생성하고 각 안의 품질·형평성·미충족 희망을 수치화한다. 서버 없이 담당자 PC에서 처리한다.

## 입력 워크플로

1. 학교 관리자: 학년도/학기, 주 5일 교시 수, 학급, 교사 가상 ID, 교과, 학급별 교사 주당시수, 교실/특별실 자원, 공통 고정 수업, 공동수업/분반/합반, 블록수업 규칙을 등록한다.
2. 교사는 표준 양식의 **교사요청** 시트에 `교사ID, 학기, 요청유형, 요일, 교시, 중요도, 사유, 비고`를 작성하고 파일로 제출한다.
3. 관리자는 여러 .xlsx를 한 번에 선택하거나 ZIP으로 묶어 업로드한다. 파일명과 교사 ID가 다를 경우 확인이 필요하며, 동일 교사·시각에 충돌하는 요청은 편성 전 검증한다.
4. 기본 시수 배정 및 교사 요청 파일만으로 결정할 수 없는 공통 업무(담임시간, 동아리, 창체, 고정 연수, 병행수업, 교실 이동 등)는 별도의 공통제약 시트로 입력한다.
5. 검증을 통과하면 `균형형`, `희망우선형`, `수업분산형` 등의 가중치 세트를 적용하여 복수 해를 구한다.
6. 도출된 해의 다양성을 확인하며 A/B/C 등을 비교하고, 사용자가 교사를 선택하여 수동 고정/재탐색할 수 있도록 한다.
7. 학급별·교사별·특별실별 주간표, 검증 보고서, 희망 충족도 분석표, 변경이력 출력.

## 핵심 데이터 모델

- `teacher`: ID, 학기, 교과, 지정주당시수, 담당학급, 연속수업 상한, 일별 상한.
- `class_group`: 학년/반 코드, 사용 교시 집합, 주당 가능 슬롯.
- `lesson_requirement`: 학급ID, 교과, 교사ID, 주당횟수, 수업길이/연속배치 규칙, 필수실 타입, 동시수업 그룹.
- `room`: 실ID, 유형, 수용 수, 점유불가 슬롯.
- `teacher_request`: ID, 유형, 대상 교사, 슬롯 범위, 중요도(필수/높음/보통/낮음), 근거, 작성자 검증 여부.
- `fixed_slot`: 전체 학교 행사, 고정 교과, 학급 시간, 특정 교사의 동시 일정.
- `solution`: 편성 ID, 생성 파라미터와 난수시드, 과목·교사·학급·실별 배정, 위반 0 검증, 지표별 점수, 총 가중 점수, 탐색 시간.

## 제약조건

### Hard (절대 위반 금지)

- 동일 시간 교사 1인 2개 수업 배정 금지.
- 동일 시간 학급(또는 분반/합반 단위) 중복 배정 금지.
- 특별실 수용 한도 및 교시별 점유 제한.
- 교사·학급 수업 불가 교시, 학교 고정수업, 주당 시수 정확 일치.
- 블록수업, 연속 수업, 교과별 주간 분포의 명시적 필수 규칙.
- 학급 총 수업시수가 시간틀 총량과 충돌하면 사전 오류.

### Soft (목적함수 최적화)

- 교사 개인 요청 충족률(중요도별 가중치).
- 요일별 수업 시수 편차, 1·마지막 교시 편중 최소화.
- 교사의 하루 긴 공강·연속수업 과다 최소화.
- 같은 학급의 동일 교과 하루 집중 분포 감소.
- 교사실/특별실 이동 최소화, 담임시간 공통 조건 충족.
- 특정 교사만 희생하지 않도록 가장 낮은 희망 충족률(최소값) 개선.

## 탐색 및 다중 대안

정확한 '가능한 모든 경우의 수' 열거는 대규모 학교에서 현실적으로 불가능할 수 있다. 먼저 입력 가능 조합의 이론상 규모(상한)를 계산하고, 실제로는 CP-SAT/제약 기반 탐색으로 유효 해 여러 개를 생성한다. 각 해가 일정 개수 이상 배정이 다르도록 차이 제약을 추가하고 재탐색한다. 학교 규모와 실행 환경에 따라 Web Worker 내 JS/WASM 솔버 또는 오프라인 데스크톱 패키지 로컬 솔버를 비교한다.

- A: 희망 충족률 우선; B: 교사 간 형평성 우선; C: 일별 수업 편중·공강 감소 우선
- 해의 주요 지표: 필수 위반 0, 희망(가중) 충족률, 최저 개인 충족률, 교사별 최대 공강, 최다 연속수업, 학급별 요일 편차, 특별실 이동 수, 두 해 사이 변경 셀 수.
- 사용자 지정 가중치를 입력받아 재평가 가능.
- 해 생성 실패 시 제약 조합의 모순과 완화 가능한 요청을 안내하고 임의 강행 배정 금지.

## 개인정보·학교 운영

- 공개 Pages에서는 익명 교사 ID와 가상 학급만 사용. 원본 요청/수업 배정표는 기기 내부에서만 파싱하고 서버로 전송하지 않는다.
- 실제 학교 자료 투입 전 학교 승인 저장 환경과 암호화·접근제어 마련이 필요하다.
- 저장 위치가 브라우저 localStorage일 경우 타인이 같은 기기 프로필을 사용할 때 접근 가능하므로, 학생·교직원 개인정보와 민감한 요청 사유를 저장하지 않도록 설계.
- 백업과 복원을 제공하되 실제 개인 정보가 들어간 자료는 가급적 별도 암호화된 작업 환경에서 처리.

## 완료 판정 기준

1. 교사별 양식 30~60개 + 시간표 기초 배정 파일을 일괄 가져오며 오류 위치를 구체적으로 표시.
2. 교사, 학급, 특별실 중복 0; 필수 제약 위반 0; 총 주당 시수 전수 검증.
3. 가능할 때 서로 구별되는 최소 3개 편성안 제시(같은 해 반복을 금지). 불가능한 경우 가능하다고 표시하지 않음.
4. A/B/C 희망 충족률·형평성·공강·연속수업을 수치와 사례로 비교.
5. 한 교사 요청 수정 후 전체 재편성 가능하고 변경 영향도 표시.
6. 교사별·학급별·실별 시간표 XLSX 및 인쇄/PDF로 출력 가능.
7. 실제 Windows PC의 오프라인 동작, 대규모 학교 성능, 학교 운영 규정 검증.
