# 나이스 기초시간표 양식 채움 기능

이 기능은 나이스에 실제 등록 가능한 공식 XLSX 규격을 보증하지 않습니다. 현재 4세대 나이스의 학교별 사용 화면에서 내려받은 **단일 학급용 빈 XLSX** 파일이 필요합니다.

## 사용

1. 전교사 시간표에서 편성안을 선택합니다.
2. 나이스 [교육과정-시간표관리-기초시간표관리]에서 현재 학교·학기에 적용되는 빈 엑셀 양식을 받습니다. 메뉴에 파일 다운로드/업로드 기능이 있는지 먼저 확인하세요. 나이스에 파일 올리기가 없으면 직접 전사 보조자료로만 사용 가능합니다.
3. '6. 나이스 입력용 파일 준비'에서 양식을 업로드합니다. 월~금의 요일 열과 1~12교시 행을 자동 인식합니다.
4. 나이스에 개설된 과목명과 JB School 교과명이 다르면 대응표에 수정합니다.
5. 학급별 XLSX와 변환 검토표 CSV가 든 ZIP을 내려받습니다. 셀의 기존 값·수식·시트 보호·미지원 교시가 있으면 변환이 중단됩니다.
6. 가상 학급으로 나이스 실등록을 시험하고 기초시간표 검증 및 반영을 별도로 수행합니다.

구형 XLS, 매크로 XLSM, 학급별 복수 시트나 임의 서식은 미지원입니다. 교사 이름, 학생 이름 등 실제 개인정보는 공개 개발 사이트에서 다루지 마세요.

참고: 2025 경기도교육청 중학교 교육과정 안내 178~180쪽에서 4세대 나이스 기초시간표 작성·검증·반영 절차를 소개하지만 모든 학교의 XLSX 올리기 기능을 보증하지는 않습니다.
