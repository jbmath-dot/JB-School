# JB School v0.2 로컬 데모 사용자 시나리오

7개 앱은 모두 **개발·시연용**입니다. 인터넷 기반 공동 회신이나 학교 공식 행정시스템 연동 기능이 없습니다. 기본 예시는 모두 가상입니다.

## 1. 교직원 회신·취합
1. 교직원 회신·취합 → 새 요청
2. 제목·마감·질문·가상 대상자 입력 후 저장
3. 가상 대상자를 선택해 응답 등록, 현황·미회신 검토
4. 회신 CSV 내보내기, 요청 마감, 완료 보관함 이동

**제한:** 다른 사용자는 이 브라우저에 생성된 회신을 볼 수 없습니다.

## 2. 회의·협의회
1. 가상 회의명, 일자, 안건/참석 대상 줄바꿈 입력
2. 결정사항·담당자·기한 입력
3. 체크박스로 후속 작업 완료 표시, 회의록 작성
4. 결정사항 CSV 다운로드 및 보관

**제한:** 서버 동기화, 참석자 서명, 공식 회의록 결재 미지원.

## 3. 교직원 연수·참석
1. 가상 연수 개설(정원 설정)
2. 참여자 가상 식별자 입력: 정원 내 신청, 정원 초과 대기
3. 등록된 참여자에 대해 담당자가 참석 체크
4. 신청 취소 시 대기 첫 대상 자동 승급, 명단 CSV 다운로드

**제한:** QR 인증과 공식 이수 인정 미지원.

## 4. 수행평가 채점·피드백
1. `STU-001` 형식의 **가상 식별자**만 사용
2. 미채점·결시·채점 완료 상태를 구분
3. 채점 완료 상태에서 모든 요소 점수(0.1점 단위) 입력
4. 자동 합계·교사 확인 표시, 결과 CSV 출력

**제한:** 샘플 루브릭 점수 합산 도구이며 학교 학업성적관리규정 적합성 보증이 아닙니다. 이미 채점 완료된 기록이 있으면 기준 변경을 차단합니다.

## 5. 학기말 기록 검토
1. `가상 ID[TAB]가상 기록 문장` 형식으로 최대 100줄 붙여넣기
2. 테스트 바이트 기준 지정 후 분석
3. UTF-8 바이트, 동일 문장, 일부 반복/강조 표현 검사
4. 탐지 이유만 CSV로 저장

**제한:** 공식 기재요령에 따른 최종 적합성 자동 판정이 아닙니다. 원문은 localStorage에 저장하지 않으며, 페이지 메모리에서만 보유합니다.

## 6. 공문·제출서류 점검
1. 일반 공문/물품 구입 품의/회의 결과보고 유형 선택
2. 각 항목을 담당자 확인·보완 필요·확인 불가로 표시
3. 수량×단가와 기재 합계를 **직접 입력**해 검산
4. 점검표 CSV 다운로드

**제한:** 실제 파일 자동 분석 또는 첨부 증빙 확인을 하지 않습니다. 미확인 항목은 통과로 처리하지 않습니다.

## 7. 업무 인수인계
1. 가상 업무명, 연간 시기, 처리 매뉴얼, 단계 입력
2. 처리 단계 체크, 완료 보관/복원
3. 업무별 인계 CSV 출력

**제한:** 실제 담당자 인증·인수 확인 서명·비공개 문서 접근권한 미지원.

## 초기화 및 백업

통합 메뉴의 `데모 데이터 관리`에서 회신 데이터를 별도로 JSON 백업·초기화할 수 있습니다. 추가 6개 모듈의 저장 데이터도 별도 JSON 백업·초기화를 지원합니다. 기록 검토 원문과 공문 점검 결과는 백업에 포함되지 않습니다.

## 실사용 전 반드시 필요한 작업

- 학교 차원의 개인정보 및 정보보호 관련 사용 승인
- 사용자 인증, 역할 기반 접근제어, 서버측 소유권·권한 검사
- 개인정보 저장·보관·파기 기준 및 암호화·감사로그
- 학업성적관리규정과 학교생활기록부 기재요령의 최신 근거 확인
- K-에듀파인/나이스 공식 서식·파일 호환성 검증
- 장애복구, 자동 테스트, 실제 학교 PC 브라우저 검증
