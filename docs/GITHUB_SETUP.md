# JB School GitHub 설치 및 배포

- 원격 저장소: https://github.com/jbmath-dot/JB-School
- 기본 브랜치: `main`
- GitHub Pages 배포 주소(설정/배포 후): https://jbmath-dot.github.io/JB-School/

## Pages 설정

Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택하세요. `.github/workflows/pages.yml`이 변경 사항을 검증하고 공개 데모 배포를 시도합니다. Actions에서 성공 여부를 확인해야 합니다.

현재 프로젝트는 **공개 저장소의 로컬 데모**입니다. 실제 교직원·학생 정보, 성적, 비공개 문서를 커밋하거나 입력하지 마세요.
