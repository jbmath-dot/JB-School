## Definition of Done

- 기능 동작만으로 완료 처리하지 않음: 입력 검증, 실패 상태, 권한, 개인정보, 내보내기, 복원, PC 사용성, 변경 이력을 검토한 후 운영 상태로 변경.
- 사용자가 완료로 처리한 업무는 기본 목록에서 즉시 제거되고 **완료 보관함**에서 복원 가능해야 함.
