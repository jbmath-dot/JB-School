# JB School v0.5 — 신규 7개 오프라인 업무 앱 기술 명세

v0.4의 17개 앱을 보존하고, 추가 7개 앱은 `src/ops-core.js`의 `definitions`와 `src/ops-ui.js`로 구현한다. 서버 호출 없이 브라우저 localStorage 및 직접 파일 내보내기를 사용한다. 실제 학교자료의 개인정보·민감정보는 입력하지 않는다.

| ID | 화면과 사용자 흐름 | 데이터 주요 필드 | 자동 점검/출력 |
|---|---|---|---|
| `budget` | 배정→예정지출→집행 항목 등록·수정·집계 | 사업명, 거래일, 구분, 금액, 메모 | 사업별 잔액=배정-집행, 가용액=배정-예정-집행, 초과경고·CSV/TXT |
| `documents`(`ops-documents` 메뉴) | CSV/TSV/XLSX 다중 업로드→동일 머리글 검증→행 취합·중복 탐지 | 원본 파일, 행 번호, 문자열 배열, 머리글 | 빈행 무시, 중복행 경고, 취합 CSV/TXT. PDF·HWP·다중시트는 미지원 |
| `progress` | 학급·교과·학기별 계획/실시/결손 시수 등록 | 학급, 교과, 학기, 단원, 계획, 실시, 결손 | 시수 합산, 진도율, 미진행 시수·CSV/TXT |
| `cleaning` | 익명 학생ID·구역·시작일 입력→순환표 자동 생성 | 날짜, 가상ID, 구역, 메모 | 중복 담당 금지, 담당 횟수 편차·CSV/TXT |
| `survey` | 질문/선택지별 집계 수 입력→그래프 | 설문명, 문항, 답변, 응답 수 | 문항별 전체/선택지 비율, 중복 선택지 금지·CSV/TXT |
| `evidence` | 활동명·일시·결과·증빙 파일명을 등록 | 일자, 활동명, 분류, 실적, 증빙파일명, 확인상태 | 확인 누락 경고, 실적 목록·CSV/TXT, 원본 첨부는 저장하지 않음 |
| `booths` | 행사/부스별 발행·사용·무효 기록→잔여 산출 | 행사, 부스, 일자, 구분, 쿠폰 수, 금액 | 잔여=발행-사용-무효, 음수 경고, 예상 사용액·CSV/TXT |

## 공통 설계

- 입력 필수값·날짜·숫자 검증, 업무 앱별 최대 1500행, 원자적 로컬 저장(실패 시 원본 유지).
- 앱 내 가상 샘플 추가, CRUD, CSV 가져오기·내보내기, TXT 점검 보고서.
- 기존 `responses`, `modules`, `extras` 데이터를 유지하며 통합 백업 v3에서 `ops` 필드를 추가. 기존 v1/v2 읽기 지원.
- `src/xlsx-reader.js`: 브라우저 내에서 XLSX 첫 번째 시트의 값만 추출. 스크립트·매크로 실행 금지. 외부 CDN 미사용.
- Github Pages 공개 버전에는 가상정보 외 입력 금지. 같은 컴퓨터의 브라우저 프로필 사용자에게 로컬 데이터 노출 가능.

## 기능검증

1. 기존 17개 메뉴에 영향 없이 신규 7개 메뉴가 표시되어야 한다.
2. 모든 앱에서 가상 예제를 추가·수정하고 CSV가 다운로드되어야 한다.
3. 통합 JSON 백업 v3의 `ops.modules`는 7개 키를 포함하고 이전 v1·v2도 파싱해야 한다.
4. 숫자형·날짜형 비정상 입력과 중복 자료를 검출한다.
5. 브라우저 네트워크 차단 후 PWA 캐시 동작은 실제 PC에서 별도 검증한다.

> 현재 XLSX 입력은 교과/감독/시간표 전용 표준 양식과 자동 연결되어 있지 않으며, 다양한 공식 서식을 전부 자동 판독한다고 주장하지 않는다.
