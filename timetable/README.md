# 전교사·전학급 시간표 자동편성 v0.6

사용 주소(배포 후): `https://jbmath-dot.github.io/JB-School/timetable/` · 오프라인 파일: `timetable/index.html`.

## 입력 순서

1. `templates/시간표_교사요청_및_기초배정_표준양식.xlsx`를 내려받습니다.
2. 시간표 담당자가 `기초배정`(학기/교사ID/교과/학급ID/주당시수/특별실유형/블록 길이), `학급시간틀`, `특별실` 시트를 작성해 업로드합니다. 행별 시수와 학급별 교시를 정확히 작성하세요. 일반 교실은 특별실 유형을 `일반`으로 적습니다.
3. 각 교사는 `교사요청` 시트를 작성해 개별 XLSX를 제출합니다. 담당자는 여러 개 선택하거나 ZIP으로 업로드합니다. 같은 교사·교시·유형·중요도의 중복 요청은 병합합니다. 요청서 학기는 기초배정과 같아야 합니다.
4. 필수 수업 불가 시간은 `수업불가/필수`로, 희망은 `수업희망` 또는 `수업비희망`과 `높음/보통/낮음`으로 기입합니다.
5. 필요한 고정수업(학급·교사·교과·요일·시작교시)을 지정합니다. 예시 파일에서 고정수업 시트는 선택 사항입니다.
6. 모든 필수 검증을 통과하면 파일 수합 후 자동으로 복수 시간표를 탐색합니다. `여러 편성안 자동 생성` 버튼으로 다시 편성할 수 있습니다.
7. A/B/C안 특성·희망 충족률·공강·연속수업을 비교하고, 학급별·교사별·특별실별 표를 확인하여 전체 XLSX와 CSV를 내려받습니다.
8. 프로젝트 JSON으로 입력 및 유효 편성안을 백업·복원할 수 있습니다. 브라우저 저장은 **사용자 버튼을 눌렀을 때만** 이루어집니다.

## 최적화 엔진

- 인터넷 없이 Web Worker에서 수행하는 랜덤화 제약 충족 탐색입니다. Worker를 사용할 수 없는 로컬 파일 실행에서는 메인 스레드 대체 탐색을 시도합니다.
- **Hard:** 교사·학급 동일 교시 중복 없음, 특별실 유형·수용·불가 교시, 교사 필수 수업불가, 학급 교시 집합, 주당시수 정확 일치, 블록 길이 연속, 고정수업.
- **Soft:** 교사 선호 중요도 가중치, 교사별 최저 희망 충족률, 공강/연속수업/요일별 편중, 한 학급 같은 교과의 하루 집중.
- 희망 우선·형평성 우선·공강 균형 우선으로 전략별 유효 해를 탐색하고 **동일 편성 중복은 제거**합니다. 상황에 따라 찾는 편성안이 3개 미만일 수 있습니다.
- **모든 가능한 경우의 수를 전수 계산하지 않습니다.** 정해진 탐색 시간 안에 해를 찾지 못한 경우 편성 불가능함이 입증된 것은 아닙니다. 이 버전은 OR-Tools CP-SAT 수준의 대규모 학교 최적화 완료·최적성 증명이 아닙니다.
- 별도의 `validateSolution` 함수로 전체 주당시수와 필수 제약을 재검사합니다. 오류가 발견된 편성안은 보여주지 않습니다.

## 제한 및 실사용 전 조건

- 지원하지 않는 복합 편성 조건: 합반·분반·교사 2인 동시 수업, 교차학년 공동선택수업, 학년 행사 시간 동시 고정 그룹, 교실 이동 시간, 동시 수업 여러 교사 수업, 정확한 최적해 보증.
- `공통제약` 시트의 고수준 정책 문장은 자동 실행하지 않습니다. 지원하지 않는 정책은 경고로 표시되며 필수 정책은 `교사요청/필수`, `학급시간틀`, `고정수업`처럼 지원 형식으로 변경해야 합니다. 무조건 성공으로 간주하지 마세요.
- 대규모 학교(수십 학급/교사)의 실제 성능과 제약 만족 가능성은 해당 학교 자료로 별도 시험해야 합니다.
- GitHub Pages 정적 웹사이트에는 계산 입력을 서버로 전송하는 코드가 없습니다. 다만 페이지 자체는 공개 개발용이며, 실제 교사명·민감한 요청 사유·학생 데이터·비공개 학교 자료를 입력하지 마세요.
- 생성된 결과는 공식 학사 운영 시간표로 사용하기 전 시간표 담당자와 학교 관리자 검토가 필요합니다.
- PWA 서비스워커는 HTTPS/localhost에서 정적 파일을 캐시합니다. 서버 없는 `file://` 실행의 브라우저 저장소/Worker는 브라우저별 제한이 있을 수 있습니다.

## 개발 테스트

`node --test tests/*.test.cjs`와 `python tests/timetable_browser.py`로 가상 자료만 시험합니다. 브라우저 UI 테스트는 샌드박스의 localhost 접속 정책 때문에 Web Worker를 모사하며, 실제 Web Worker 실행·서비스워커 오프라인 재접속·실제 학교 규모는 별도 실기기 검증이 필요합니다.
