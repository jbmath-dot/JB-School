# JB School — 학교 업무 자동화 (v0.2.0)

**현재 단계: 공개 시연용 오프라인 우선 웹앱.** 7개 도구의 브라우저 로컬 시연 기능이 있으며 **실제 공동 운영, 인증, 권한 관리, 서버 저장, 공식 기록·평가 처리는 아직 구현되지 않았습니다.**

- [데모 주소](https://jbmath-dot.github.io/JB-School/) — GitHub Pages가 켜져 있을 때만 접속 가능
- [저장소](https://github.com/jbmath-dot/JB-School)
- 기존 `jb-webapps`와 `math-class-webtools` 저장소에는 영향을 주지 않습니다.

## 작동하는 로컬 시연 기능 (7개)

| 도구 | 구현된 로컬 시연 | 아직 필요한 실제 운영 기능 |
|---|---|---|
| 교직원 회신·취합 | 요청 4단계 작성, 가상 응답, 회신율·미회신 집계, 마감·보관, CSV | 교직원 로그인, 대상자별 서버 인증·중복 제출 방지, 실시간 취합 |
| 회의·협의회 | 가상 회의·안건 생성, 참석 대상 입력, 결정사항 배정·완료, 회의록, CSV | 공유 일정, 참석 확인, 회의록 결재·감사 이력 |
| 교직원 연수·참석 | 연수 개설, 정원·대기·중복 방지, 참석 체크, 명단 CSV | 인증된 교직원 신청 및 출석 증빙·이수 확인 |
| 수행평가 채점·피드백 | 가상 ID, 루브릭·부분점수, 결시/미채점 구분, 총점·확인·CSV | 실제 평가 규정 검증, 안전한 저장·백업·접근통제 |
| 학기말 기록 검토 | 익명 문장 바이트 수, 동일 문장·표현 경고, 검토 CSV | 공식 기재요령 근거별 규칙·문맥 판단, 승인된 운영환경 |
| 공문·제출서류 점검 | 유형별 체크리스트, 확인 불가 표시, 금액 수동 검산, CSV | 실제 첨부 분석, 공문 규정·학교 서식 검증 |
| 업무 인수인계 | 가상 매뉴얼 생성, 처리 단계·완료·보관, CSV | 사용자별 인수·인계 확인, 공동 이력·첨부 권한관리 |

**모든 기본 예시는 가상입니다.** 어떤 경우에도 공개 데모에 실제 학생 이름·성적·학교생활기록부·교직원 개인정보·비공개 공문·비밀번호·토큰을 입력하지 마세요.

## 실행

웹: https://jbmath-dot.github.io/JB-School/

오프라인: 전체 폴더를 다운로드한 뒤 `index.html`을 Chrome/Edge에서 실행할 수 있습니다. 로컬 페이지로 연 경우 서비스 워커 기반 PWA 설치는 불가능하지만 기본 웹앱은 인터넷 없이 실행됩니다. 설치형 PWA 테스트:

```bash
python -m http.server 8000
```

`http://localhost:8000`을 열고 첫 캐시 완료 후 네트워크를 차단하여 재접속을 테스트합니다. 브라우저가 사이트 데이터를 지우면 로컬 데이터가 사라집니다. `데모 데이터 관리`에서 JSON 백업을 내려받으세요.

## 데이터 범위 및 보안

- 브라우저 `localStorage` (암호화되지 않음): 회신·회의·연수·익명 채점·인수인계 **가상** 입력 내용. 브라우저/기기 간 동기화되지 않습니다.
- 메모리(탭 닫으면 소실): 기록 검토 원문·점검표 검사 결과. CSV 수동 다운로드만 가능합니다.
- **외부 서버로 사용자 입력을 전송하지 않으며** 별도 API 키·데이터베이스·외부 CDN이 없습니다.
- GitHub Pages에 공개된 JS 코드는 누구나 볼 수 있습니다. 향후 저장소를 Private으로 바꿔도 현재와 같은 무료 Pages 공개 서비스가 유지되는 것은 아닙니다.
- 실제 서비스로 전환하려면 학교 승인, 학생/교직원 데이터 분류, 인증·서버 권한검사, 감사·보존·삭제·백업 정책을 마련해야 합니다.

## 테스트

```bash
npm test
```

17개의 Node.js 단위 테스트가 있으며, 개발 컨테이너에서는 스크립트를 인라인 삽입한 Chromium 브라우저에서 메뉴 이동·주요 폼 제출을 확인했습니다. 로컬 파일과 실기기 PWA 설치 동작은 별도 검증이 필요합니다.

브라우저 시연 테스트 (Playwright Python 설치 환경):

```bash
python tests/browser_smoke.py
```
