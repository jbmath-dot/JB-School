# JB School — 오프라인 우선 학교 업무도구 (v0.4.0)

> **기존 7개 앱 유지 + 신규 10개 앱 추가 = 17개 로컬 업무도구.** 서버 로그인 및 교직원 간 공동 저장은 후순위로 유예합니다. 공개 Pages에서는 비식별 가상 데이터만 테스트하세요.

## 바로 실행

- 공개 데모(활성 배포 후): https://jbmath-dot.github.io/JB-School/
- PC 오프라인: ZIP을 압축 해제하고 `index.html`을 Edge/Chrome으로 열거나 `python -m http.server 8000`으로 로컬 서버 실행.
- 기존 7개 도구는 메뉴와 데이터가 보존됩니다. 신규 앱 10개의 입력, 수정, 삭제, CSV 가져오기·내보내기, 점검 TXT 및 업무별 자동화가 추가됐습니다.
- 기존 v1 JSON 통합 백업도 읽을 수 있으며 신규 v2 백업에는 17개 로컬 업무 앱 정보가 포함됩니다. 백업 복원은 현재 데이터를 덮어씁니다.

## 신규 10개 도구

1. 시험 감독·대체수업 편성 — 담당 횟수 기준 자동 배정 및 시간 중복 확인
2. 수학 시험지·문항 검토 — 5지선다 답안 분포와 총점 점검
3. 표창·공적조서 작성 — 공적 초안·검토상태와 TXT 초안
4. 창체·봉사 기록 대조 — 동일 학생 동일 시각 중복 점검
5. 학생 자리배치·모둠 편성 — 무작위 좌석과 모둠 분할
6. 수학 클리닉·튜터링 관리 — 회차별 목표·상태·보충 기록
7. 학사일정·업무 마감 달력 — 기한·준비 시작일·완료 구분
8. 수학대회 운영·심사 — 심사위원별 점수 평균 및 공동 순위
9. 체험학습·현장학습 준비 — 안전·안내·교통 업무 체크리스트
10. 업무분장 분석·조정 — 담당자별 가중 업무시간 비교

상세 설계와 제한사항: [`docs/NEW_10_APPS_SPEC.md`](docs/NEW_10_APPS_SPEC.md)

## 주의 사항

- 이 프로젝트는 데이터가 브라우저에 저장되는 **로컬 기능 MVP**이지, 공식 NEIS/K-에듀파인/학교생활기록부 시스템이나 학교 보안승인을 대체하지 않습니다.
- 브라우저 localStorage는 암호화되지 않으므로 실제 학생·교직원 개인정보, 성적 및 비공개 학교 기록을 입력하지 마세요.
- 시험 감독의 불가능 교시, 학교 학사 일정, 수학대회 배점, 표창 양식은 학교마다 달라 **자동 결과의 공식 적합성은 검증되지 않았습니다.**
- PWA 설치 및 실제 네트워크 차단 재접속은 추가 실기기 검증이 필요합니다.

> **서버 없이 사용하는 로컬 업무도구 7종.** 개발용 가상 데이터로 입력·조회·검토·내보내기·백업을 시험할 수 있습니다. **공식 업무 시스템과 보안 심사를 대체하지 않습니다.**

- 개발용 웹앱: https://jbmath-dot.github.io/JB-School/ (GitHub Pages 활성 시)
- 저장소: https://github.com/jbmath-dot/JB-School
- 학교 실제 자료는 공개 웹앱에 입력하지 마세요. 브라우저 `localStorage`는 암호화되지 않습니다.
- 교직원 간 서버 전송, 실시간 공동 회신, 로그인 및 권한 제어는 **다음 단계로 유예**했습니다.

## 백업과 데이터 복원

1. 왼쪽 **데모 데이터 관리** 메뉴로 이동합니다.
2. **전체 백업 내려받기**를 클릭해 `JB-School-통합백업-날짜.json`을 저장합니다.
3. 다른 기기나 브라우저에 복원하려면 **통합 백업 복원**으로 같은 파일을 선택합니다.
4. 복원은 회신·회의·연수·익명 채점·인수인계 데이터를 모두 교체합니다. **기존 데이터는 복원 전에 먼저 백업하세요.**

학교생활기록부 문장 원문과 공문 점검 결과는 브라우저 메모리에서만 보유하므로 통합 백업에 들어가지 않습니다. CSV로 별도 내려받을 수 있습니다. JSON과 CSV에 개인정보가 담길 수 있으므로 보호되는 위치에 저장하고 공유하지 마세요.

## 로컬 실행 / 설치

**인터넷 없이 직접 실행:** ZIP 압축을 해제해 `index.html`을 Edge 또는 Chrome에서 열면 기본 화면·도구를 사용할 수 있습니다. 브라우저 정책에 따라 `file://` 저장소가 사이트별로 달라질 수 있어 정기 백업을 권장합니다.

**PWA 설치 테스트:**

```bash
python -m http.server 8000
```

`http://localhost:8000`으로 접속하고 Chrome/Edge에서 앱 설치를 시도할 수 있습니다. 설치와 오프라인 재접속은 PC 실기기 확인이 필요합니다. 개발 테스트 환경에서는 브라우저의 로컬 HTTP 접속이 정책에 의해 차단되어 실제 서비스워커 재접속 검증은 완료하지 못했습니다.

## 보안과 책임 경계

- 사용자 입력을 서버에 업로드하는 코드는 없습니다. GitHub Pages 정적 파일은 온라인에서 내려받지만, 사용자가 입력한 값은 브라우저 로컬 저장공간 또는 메모리에 머뭅니다.
- `localStorage`는 암호화되지 않으며, 다른 사용자가 같은 브라우저 프로필에 접근하면 볼 수 있습니다.
- 공식 문서 작성·평가·학교생활기록부 입력에 앞서 학교 담당자 및 규정 검토가 필요합니다.
- 앱의 `검토 필요`는 기계적 탐지이며, `문제없음` 판정이 아닙니다.
- **Public 저장소에는 실제 교직원/학생 정보, 민감 자료, 비밀번호/API 비밀키를 업로드하지 않습니다.**
