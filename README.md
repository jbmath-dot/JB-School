## 백업과 데이터 복원

1. 왼쪽 **데모 데이터 관리** 메뉴로 이동합니다.
2. **전체 백업 내려받기**를 클릭해 `JB-School-통합백업-날짜.json`을 저장합니다.
3. 다른 기기나 브라우저에 복원하려면 **통합 백업 복원**으로 같은 파일을 선택합니다.
4. 복원은 회신·회의·연수·익명 채점·인수인계 데이터를 모두 교체합니다. **기존 데이터는 복원 전에 먼저 백업하세요.**

학교생활기록부 문장 원문과 공문 점검 결과는 브라우저 메모리에서만 보유하므로 통합 백업에 들어가지 않습니다. CSV로 별도 내려받을 수 있습니다. JSON과 CSV에 개인정보가 담길 수 있으므로 보호되는 위치에 저장하고 공유하지 마세요.

## 로컬 실행 / 설치

**인터넷 없이 직접 실행:** ZIP 압축을 해제해 `index.html`을 Edge 또는 Chrome에서 열면 기본 화면·도구를 사용할 수 있습니다. 브라우저 정책에 따라 `file://` 저장소가 사이트별로 달라질 수 있어 정기 백업을 권장합니다.

**PWA 설치 테스트:**

```bash
python -m http.server 8000
```

`http://localhost:8000`으로 접속하고 Chrome/Edge에서 앱 설치를 시도할 수 있습니다. 설치와 오프라인 재접속은 PC 실기기 확인이 필요합니다. 개발 테스트 환경에서는 브라우저의 로컬 HTTP 접속이 정책에 의해 차단되어 실제 서비스워커 재접속 검증은 완료하지 못했습니다.

## 개발 테스트

```bash
npm test                  # 도메인 단위 테스트
python tests/browser_smoke.py
python tests/browser_full.py
```

브라우저 테스트는 로컬 HTTP 접근 제약 때문에 HTML·JS·CSS를 브라우저 메모리에 직접 넣고 기능을 검증합니다. 가상 ID와 가상 문장만 사용합니다.

## 보안과 책임 경계

- 사용자 입력을 서버에 업로드하는 코드는 없습니다. GitHub Pages 정적 파일은 온라인에서 내려받지만, 사용자가 입력한 값은 브라우저 로컬 저장공간 또는 메모리에 머뭅니다.
- `localStorage`는 암호화되지 않으며, 다른 사용자가 같은 브라우저 프로필에 접근하면 볼 수 있습니다.
- 공식 문서 작성·평가·학교생활기록부 입력에 앞서 학교 담당자 및 규정 검토가 필요합니다.
- 앱의 `검토 필요`는 기계적 탐지이며, `문제없음` 판정이 아닙니다.
- **Public 저장소에는 실제 교직원/학생 정보, 민감 자료, 비밀번호/API 비밀키를 업로드하지 않습니다.**

## 구조

`src/core.js`와 `src/app.js`는 회신과 대시보드, `src/modules-core.js`와 `src/modules-ui.js`는 나머지 6개 앱, `src/local-tools-core.js`는 통합 백업·출력 및 텍스트 파서를 담당합니다. `sw.js`가 정적 파일을 오프라인 캐시합니다. 자세한 운영 제한은 `docs/ROADMAP.md`를 참고하세요.
